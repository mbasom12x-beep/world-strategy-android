# استراتيجية العالم — نسخة أولية 0.1

مشروع Android Studio مبدئي، بواجهة لعبة مبنية باستخدام HTML/SVG داخل Android WebView.

## الموجود حالياً
- شاشة أفقية مناسبة للهاتف.
- خريطة عالم تخطيطية مدمجة داخل المشروع (تعمل دون إنترنت).
- سحب وتحريك للخريطة، زوم بالأزرار وبإصبعين.
- اختيار مناطق على الخريطة.
- موارد وخزينة ودخل يومي.
- تطوير، تجنيد، وإنهاء اليوم.
- حفظ محلي للتقدم عبر localStorage.

## ملاحظة مهمة
هذه نسخة أولية قابلة للتجربة وليست لعبة مكتملة. أشكال القارات تخطيطية وليست حدود دول دقيقة. الخطوة التالية هي استبدال الرسم التخطيطي ببيانات جغرافية دقيقة وتقسيم الدول إلى مناطق، ثم إضافة حفظ واختبارات أوسع.

## طريقة التشغيل
1. فك ضغط الملف.
2. افتح مجلد `world_strategy_android` في Android Studio.
3. اسمح لـ Gradle بمزامنة المشروع.
4. شغّل التطبيق على محاكي أو جهاز أندرويد.

يتطلب Android Studio مع Android SDK 35 وGradle متوافقاً مع Android Gradle Plugin 8.7.3.
